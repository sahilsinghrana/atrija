## 1. Overview

**One-liner:** Dynamically select compressed texture formats based on device GPU capabilities to reduce memory usage and improve loading performance.

**Problem:** High-resolution textures consume significant memory and bandwidth, especially on mobile devices with limited resources. This can lead to longer load times, increased battery drain, and potential frame drops.

**Solution:** Implement a texture loading system that detects available GPU texture compression formats (e.g., ASTC for mobile GPUs, BC7 for desktop) and loads the appropriate compressed texture format. Fallback to uncompressed textures if necessary. This reduces memory footprint and bandwidth usage while maintaining visual quality.

## 2. User Stories

- As a mobile user, I want the app to use memory-efficient textures so that it loads faster and runs smoother on my device.
- As a desktop user, I want high-quality textures when my GPU supports them, ensuring the best visual fidelity.
- As a user on a metered connection, I want reduced texture data transfer to save bandwidth.
- As a user with limited device memory, I want the application to avoid out-of-memory crashes by using compressed textures.

## 3. Technical Specification

### 3.1 Architecture

- **New module:** `public/js/texture-manager.js` – Handles texture loading with format detection and fallback.
- **Modified texture loading:** Replace direct `new THREE.TextureLoader().load()` calls with calls to `TextureLoader.loadWithFallback(url, options)`.
- **Feature detection:** Use `WEBGL_compressed_texture_astc` and `WEBGL_compressed_texture_bc` extensions to determine supported formats.
- **Texture atlas:** Where applicable, combine multiple textures into an atlas to reduce draw calls (optional extension).
- **Cache:** Cache loaded textures in a Map to avoid re-downloading.

### 3.2 Implementation Details

#### Step 1: Create texture-manager.js

```javascript
(function () {
  'use strict';
  const textureCache = new Map();
  let astcSupported = false;
  let bcSupported = false;

  function detectTextureSupport() {
    const gl = document.createElement('canvas').getContext('webgl2') ||
               document.createElement('canvas').getContext('webgl');
    if (!gl) return;
    astcSupported = !!gl.getExtension('WEBGL_compressed_texture_astc');
    bcSupported = !!gl.getExtension('WEBGL_compressed_texture_bc');
  }

  function getTextureExtension() {
    if (astcSupported) return '.astc';
    if (bcSupported) return '.bc7';
    return ''; // uncompressed
  }

  function loadTexture(url, options = {}) {
    // Check cache
    const cached = textureCache.get(url);
    if (cached) return cached;

    const ext = getTextureExtension();
    const urlWithExt = url.replace(/\.(png|jpe?g)$/, ext + '$1');

    const loader = new THREE.TextureLoader();
    loader.setCrossOrigin('anonymous');

    return new Promise((resolve, reject) => {
      loader.load(
        urlWithExt,
        (texture) => {
          texture.cache = true;
          textureCache.set(url, texture);
          resolve(texture);
        },
        undefined,
        (error) => {
          // Fallback to uncompressed if compressed fails
          if (ext !== '') {
            loader.load(
              url,
              (texture) => {
                texture.cache = true;
                textureCache.set(url, texture);
                resolve(texture);
              },
              undefined,
              reject
            );
          } else {
            reject(error);
          }
        }
      );
    });
  }

  // Expose API
  window.TextureLoader = {
    load: loadTexture,
    setCrossOrigin: (value) => {
      // Update internal loader's crossOrigin
      // For simplicity, we expose a setter that recreates the loader on call
      // In practice, we would store the loader instance
    }
  };

  // Run detection on load
  detectTextureSupport();
})();
```

#### Step 2: Integrate with existing texture usage

Replace texture loading in scene-init.js and scene modules (e.g., scene-moon.js, scene-stars.js, scene-flowers.js) with:

```javascript
const texture = await TextureLoader.load('textures/moon.jpg');
// or
TextureLoader.load('textures/moon.jpg').then(texture => { ... });
```

#### Step 3: Provide fallback textures

Ensure that uncompressed textures are available as fallback in the repository.

### 3.3 Mobile Considerations

- Prioritize ASTC format for mobile GPUs (widely supported on modern Adreno, Mali, PowerVR).
- If ASTC not available, try ETCC2 (if supported) or fallback to uncompressed.
- Consider lower resolution textures for mobile even when compressed.

### 3.4 Cache Management

- Implement a maximum cache size (e.g., 50 textures) to prevent unbounded memory growth.
- Use LRU eviction if needed.

## 6. Dependencies and Risks

**Dependencies:** Three.js texture loading mechanism, GPU extension detection via WebGL.

**Risks:**
- Some mobile browsers may not expose the necessary extensions → fallback to uncompressed.
- Compressed textures may require specific server MIME types → ensure .astc and .bc7 files are served correctly.
- Increased complexity in texture asset pipeline → need to generate and maintain compressed versions of textures.
