## 1. Overview

**One-liner:** Add a setting to control the density of flowers (sunflowers, tulips, lilies) in the 3D scene, allowing users to trade off visual richness for performance.

**Problem:** The current flower density is fixed and may be too high for low-end mobile devices, causing frame drops. Conversely, high-end desktop users may desire a denser flower field for greater visual immersion.

**Solution:** Introduce a user-adjustable setting (e.g., via a dropdown in the theme switcher or a new floating button) that lets users choose between Off, Low, Medium, and High flower density. The setting is stored in sessionStorage and read by the flower creation logic to adjust the number of spawned flowers.

## 2. User Stories

- As a mobile user with a low-end device, I want to reduce flower density so that the site runs smoothly without sacrificing the core experience.
- As a desktop user with a powerful GPU, I want to increase flower density to enjoy a more lush and immersive flower field.
- As a user who prefers minimalism, I want to turn off flowers entirely to focus on other scene elements.
- As a returning user, I want my flower density preference to persist for the duration of my session.

## 3. Technical Specification

### 3.1 Architecture

- **New module:** `public/js/flower-density-control.js` – Manages the UI setting and communicates the density value to the flower creation logic.
- **Modified flower logic:** Update `src/js/scene/scene-flowers.js` and `src/js/scene/scene-flowers-objects.js` to read a global variable or event for density scaling.
- **Storage:** Use `sessionStorage` to persist the setting during the session.
- **UI:** Integrate with the existing theme switcher (idea-029) or add a new floating button that opens a small menu.

### 3.2 Implementation Details

#### Step 1: Create flower-density-control.js

```javascript
(function () {
  'use strict';
  const DENSITY_KEY = 'atrija-flower-density';
  const DENSITY_LEVELS = {
    off: 0,
    low: 0.33,
    medium: 0.66,
    high: 1.0
  };
  let currentDensity = DENSITY_LEVELS.medium; // default

  // Load from sessionStorage
  const saved = sessionStorage.getItem(DENSITY_KEY);
  if (saved && DENSITY_LEVELS[saved] !== undefined) {
    currentDensity = DENSITY_LEVELS[saved];
  }

  // Expose API
  window.FlowerDensity = {
    getLevel: () => currentDensity,
    setLevel: (level) => {
      if (DENSITY_LEVELS[level] !== undefined) {
        currentDensity = DENSITY_LEVELS[level];
        sessionStorage.setItem(DENSITY_KEY, level);
        // Notify any listeners (e.g., via custom event)
        window.dispatchEvent(new CustomEvent('flower-density-changed', { detail: { level: currentDensity } }));
      }
    },
    // For backward compatibility, also accept numeric value
    setValue: (value) => {
      currentDensity = Math.max(0, Math.min(1, value));
      sessionStorage.setItem(DENSITY_KEY, currentDensity.toString());
      window.dispatchEvent(new CustomEvent('flower-density-changed', { detail: { level: currentDensity } }));
    }
  };

  // Listen for changes from other scripts (if any)
  window.addEventListener('flower-density-set', (e) => {
    FlowerDensity.setLevel(e.detail.level);
  });
})();
```

#### Step 2: Modify scene-flowers.js

In the flower creation functions (e.g., `createSunflowers`, `createTulips`, `createLilies`), read the density level and multiply the flower count by it.

```javascript
// Example for createSunflowers
function createSunflowers(scene, count) {
  // Get density scale
  const densityScale = window.FlowerDensity ? window.FlowerDensity.getLevel() : 1.0;
  const actualCount = Math.floor(count * densityScale);
  if (actualCount === 0) return; // early exit if off

  // ... rest of the function using actualCount instead of count
}
```

Do the same for `createTulips` and `createLilies`.

#### Step 3: Modify scene-flowers-objects.js

Similarly, in the object creation functions that call the above, ensure they pass the density-scaled count.

#### Step 4: Integrate UI

Option A: Extend the theme switcher (public/js/theme-switcher.js) to include a density submenu.
Option B: Create a new floating button (similar to the reader mode button) that opens a density menu.

We'll implement Option B for simplicity.

Add a new button in `index.astro` (or via a standalone module that injects the button) with an ID `#flower-density-button`.

Create a new module `public/js/flower-density-button.js` that:
- Creates a button with a flower icon.
- On click, shows a small menu with options: Off, Low, Medium, High.
- Updates the setting via `window.FlowerDensity.setLevel()`.
- Updates the button UI to reflect the current level.

#### Step 5: Add styles

Add necessary CSS for the button and menu in `main.css` or via a JS-injected style tag. Since we cannot modify main.css, we can inject a style tag via JS.

## 5. Acceptance Criteria

- [ ] Users can select flower density Off, Low, Medium, High via the UI.
- [ ] Selection persists in sessionStorage for the duration of the session.
- [ ] Flower count scales correctly: Off -> 0, Low -> ~1/3, Medium -> ~2/3, High -> full.
- [ ] No console errors when FlowerDensity API is accessed before initialization (graceful fallback to 1.0).
- [ ] All existing flower-related functionality remains intact when density is set to high (default).
- [ ] All unit tests pass.
- [ ] Changelog entry added.

## 6. Dependencies & Risks

**Dependencies:** Existing flower creation logic in scene-flowers.js and scene-flowers-objects.js.

**Risks:**
- If the flower creation logic is refactored to not use a simple count parameter, the density scaling may need adjustment.
- Users may expect the density change to take effect immediately without reload; we currently require a page reload to respawn flowers with the new density. Mitigation: implement dynamic flower respawning in a future iteration.
- Adding a new UI button may clutter the interface; ensure it is styled appropriately and placed in a non-obtrusive location (e.g., bottom-left near the reader mode button).
